PromptVault Enterprise Knowledge Base & Tutorials

Complete guide to mastering prompt engineering, nested folders, smart variables, and offline synchronization

01

Getting Started & Prompt Creation

Create prompts using the "+ New Prompt" button or the Quick Paste bar. Assign system personas, target AI models (ChatGPT, Claude, Gemini, Midjourney), and categorize them for instant lookup.

02

Folders, Subfolders & Projects

Structure your client workflows (e.g. Clients → Acme Corp → SEO Research). Move prompts between folders using the "Move" action with relational database integrity.

03

Smart Dynamic Variables {{var}}

Wrap placeholders in {{product}} or [tone]. Click "Fill Variables" to open an interactive runner where you supply dynamic values and copy compiled prompts in seconds.

04

Revision History & 1-Click Rollback

Every edit automatically creates a version snapshot. Click the History button to inspect prior versions and restore them. Restores are safe and non-destructive.

05

Duplicate Prompt Prevention

The platform includes intelligent fuzzy similarity detection. If you attempt to save an identical or near-duplicate prompt, the system alerts you and offers View Existing, Save Anyway, or Replace.

06

Offline Sync & Android APK

PromptVault uses local IndexedDB storage. You can view, copy, and create prompts offline. When connectivity is restored, pending changes sync automatically to the database.
